# Jot

A small, local-first notes app for macOS. Capture an idea in a floating window, keep a checklist beside your work, and browse notes in a searchable modal. Jot is an independent app inspired by the convenience of quick notes; it does not use Raycast code or services.

**[Download the macOS preview DMG](https://github.com/arthurhux/Jot/releases/tag/v1.0.1-preview.1)** · Apple silicon · macOS 14+

This preview is ad hoc signed and has not been notarized by Apple. macOS may block the first launch; see [Apple's instructions](https://support.apple.com/en-us/102445) for approving a specific app that you trust. Intel builds and automatic updates are not included yet.

## Features

- Rich text with Markdown shortcuts, headings, checklists, lists, links, quotes, and highlighted code blocks.
- A focused writing view with a Browse Notes modal, separate Pinned and Notes sections, search, and recently deleted notes.
- No artificial note-count limit. The modal shows a count, not a quota.
- Automatic titles from the first meaningful line; a manual rename takes priority.
- Settings for the global shortcut, floating behavior, and automatic window sizing.
- Automatic local saving, with a backup of the previous saved document.
- Selection and scroll restoration when switching notes.
- A floating window, menu bar access, and a global keyboard shortcut, without a Dock or Command–Tab entry.
- Markdown and text import, Markdown export, and recoverable recently deleted notes.

Cloud sync, collaboration, and mobile apps are not included. Jot uses a native AppKit shell and a locally bundled Tiptap editor inside WebKit. The editor runs without a network connection.

## Requirements

macOS 14 Sonoma or later. Building requires Xcode command line tools with Swift 6.0 or later, plus Node.js 20 or later and npm for the editor. An Apple developer account is not needed for the local build. The packaged app does not need Node.js, npm, or a copy of this source folder to run.

For public downloads, users should install a packaged app from **GitHub Releases**, rather than GitHub's source archive. The current local app is Apple silicon only and ad hoc signed; trusted public distribution still needs Developer ID signing and notarization. See [Sharing Jot on GitHub](DISTRIBUTION.md) for installation steps and release requirements.

## Build and open

To create a drag-to-Applications disk image:

```sh
./scripts/build-dmg.sh
```

This builds the app and creates `dist/Jot-<version>-<architecture>.dmg` with an Applications shortcut, installation instructions, and a separate SHA-256 checksum. Use `./scripts/build-dmg.sh --skip-build` to package an existing app. The DMG preserves the app's signature; it does not add Developer ID signing or notarization.

From this folder:

```sh
./scripts/build-app.sh
open dist/Jot.app
```

The build script installs the locked editor dependencies, builds the web assets and release executable, packages `dist/Jot.app`, and signs it locally with an ad hoc signature. It does not install or open the app. You can move the built app to your Applications folder when ready.

Swift build products, module caches, and signing staging files use a temporary directory outside the source workspace. This avoids Finder metadata from synced Documents folders interfering with macOS code signing. The build cache has a stable folder name based on your user and this project's path, so subsequent builds can reuse it. Set `JOT_BUILD_DIR` to choose a different build cache, preferably outside any synced folder:

```sh
JOT_BUILD_DIR=/tmp/JotBuild ./scripts/build-app.sh
```

To rebuild only the native app after the editor has been built:

```sh
./scripts/build-app.sh --skip-editor
```

The source icon is generated by `scripts/generate-icon.swift`; the PNG preview and macOS `.icns` file are in `Assets/`.

The script builds for the current Mac's processor architecture. A build made on Apple silicon runs natively on other Apple silicon Macs with macOS 14 or later; build on an Intel Mac for an Intel-native executable. The editor files are included in the app bundle, with no dependency on the build machine's paths.

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| Control–Option–J | Show or hide Jot from any app |
| Command–N | New note |
| Command–P | Open Browse Notes |
| Command–, | Open Settings |
| Command–F | Search notes |
| Command–Shift–F | Find text in the current note |
| Command–Shift–M | Toggle compact view |
| Command–Shift–P | Toggle always on top |
| Command–Shift–E | Export the current note as Markdown |
| Command–O | Import Markdown or plain text |
| Command–Delete | Move the selected note to Recently Deleted |
| Command–B / Command–I | Bold / italic |
| Command–Z / Command–Shift–Z | Undo / redo |
| Escape | Close find or search; otherwise hide Jot |
| Command–W | Hide the notes window |
| Command–Q | Save and quit |

The default global shortcut is **Control–Option–J**. Open **Settings** using Command–comma, the title-bar Actions menu, or the menu-bar menu, then click the shortcut badge to record a replacement. The shortcut uses the macOS hotkey API and does not require Accessibility permission. Jot requests exclusive registration and reports conflicts; it preserves the previous shortcut if a replacement is unavailable. Other apps using their own event interception can still take priority. Jot runs as a menu-bar app, with no Dock or Command–Tab entry. Closing the window hides it and keeps the process and shortcut running; Activity Monitor still lists Jot. Choose **Quit Jot** from its menu-bar menu or press Command–Q while the panel has focus to stop it. Jot must remain running for its shortcut to work.

The panel floats above other apps by default. It joins desktop Spaces and eligible full-screen app Spaces without activating Jot or switching away from the current app. Command shortcuts are routed through the panel while it has keyboard focus, so they continue to work while another app's menu bar is visible. Change floating behavior in Settings or the Actions menu.

Compact view automatically fits its height to the note. Resizing it by hand pauses automatic fitting; enable automatic fitting in Settings to resume. The footer's type icon shows or hides the formatting toolbar.

## Motion and accessibility

Jot stays in dark appearance. The UI uses the supplied tweakcn tokens from `Theme/tweakcn.css`; `scripts/generate-theme.mjs` generates matching web variables and native Swift colors from that file. Edit the theme source and rebuild the editor to update both surfaces. Colors, border shades, note selection, fonts, and corner radii share these tokens.

Toolbar, modal, note-action, and menu-bar icons come from the pinned official Lucide package. The web editor renders Lucide SVGs directly; the build generates matching native Core Graphics paths. Controls share a 16-point canvas and an absolute 1.5-point stroke with round caps and joins. Both renderers scale geometry independently of the stroke, keeping the weight consistent at different sizes. Icons and theme files are included in the app bundle and require no network connection.

Standard interface icons share the theme's neutral muted-foreground color; active controls use a background or outline instead of changing the icon color. Browse Notes and Settings use a black translucent backdrop that keeps the surrounding note sharp. Native in-window frosting is confined to the rounded modal card, with a fine highlighted rim and a solid card fallback when macOS Reduce Transparency is enabled. The note browser's native search field receives keyboard focus immediately, and the underlying note cannot be edited while a modal is open.

Search uses a native insertion caret without the default blue field outline. Pointer hover and arrow keys share an immediate row highlight; pin, trash, and restore actions appear on that row. Hovering does not scroll the list. Matching pinned notes appear above the remaining results, and the dialog height follows the filtered count. Settings keeps switches and the shortcut button on a shared trailing edge, uses spaced native shortcut symbols, and omits an appearance selector because the app stays dark.

Typing, switching notes, keyboard commands, modal presentation, and automatic height updates respond immediately. Pointer controls use a restrained 0.97 press scale and approximately 120 ms settling; pointer-triggered compact-window transitions use approximately 180 ms. These timings are centralized in the native `MotionTokens` and editor CSS variables. macOS **Reduce Motion** disables the spatial effects, and the editor also respects increased contrast.

## Your notes

New notes name themselves from the first non-empty line you type. That opening line expresses the note's intent: a heading, task, or thought. Markdown markers are removed, long titles are shortened at a word boundary to at most 72 characters, and Unicode stays intact. The title follows changes to the opening text until you edit the title yourself. To resume automatic naming, choose **Actions → Use Automatic Title**. This rule runs locally and uses your own words. Existing named notes retain their titles; older unnamed notes receive a title from their saved opening text.

Notes are saved under:

```text
~/Library/Application Support/Jot/notes.json
```

The JSON document contains rich text content and note metadata. Jot saves the previous valid snapshot as `notes.backup.json` alongside it. Notes in **Recently deleted** can be restored; notes deleted more than 60 days ago are purged on the next app launch. Unreadable saved files are preserved under a unique recovery filename, and Jot attempts to load the backup. Export important notes or back up the Jot folder for an additional copy. Local data is not encrypted by Jot; it uses the protection provided by your macOS account and disk settings.

Imported files must be UTF-8 Markdown or text, no larger than 10 MB per file. Markdown export includes the note body; the note title becomes the suggested filename.

## Development checks

The native browser uses a virtualized AppKit table with stable note identities, native accessibility scrolling, and first/last-note accessibility actions. Search includes displayed fallback titles such as **Untitled**. Find/link controls adapt to narrow editor widths; modification dates include the year for older notes.

See [UI regression checks](docs/ui-regression-checks.md) for the isolated stress-test app, fixture datasets, and validation limits.

Run the native tests:

```sh
swift test --scratch-path /tmp/JotTests --disable-sandbox
```

Run the editor checks:

```sh
npm --prefix Editor test
npm --prefix Editor run build
```

Exercise the packaged WebKit editor and its native bridge:

```sh
./dist/Jot.app/Contents/MacOS/Jot --smoke-test
```

This opens the app using an automatically created temporary data folder, checks the bundled editor, Markdown formatting, native content updates, note switching, find, pinning, deletion, and restoration, then prints `JOT_SMOKE_TEST_PASS` or a failure and exits. It does not use your usual notes folder. The temporary folder remains available for inspection.

For an interactive development session with isolated notes, set an explicit data folder:

```sh
JOT_DATA_DIR="$(mktemp -d /tmp/jot-dev.XXXXXX)" ./dist/Jot.app/Contents/MacOS/Jot
```

`JOT_DATA_DIR` takes precedence over the default folder, including in smoke-test mode. Use a fresh folder for tests because the smoke test creates and changes notes there.

Useful manual checks after building: create and format a note, switch notes and reopen the app to check restoration, search and pin a note, restore a recently deleted note, and export then import Markdown. Check the global shortcut and compact window with another app active, and verify Reduce Motion in macOS Accessibility settings.

## Project layout

- `Sources/Jot/` — native macOS app and WebKit bridge.
- `Editor/` — rich text editor source and locked npm dependencies.
- `Sources/Jot/Resources/Editor/` — generated editor resources.
- `Tests/` — native tests.
- `scripts/` — application packaging and icon generation.
- `Assets/` — original Jot app icon.
- `Theme/tweakcn.css` — shared source for the supplied dark theme.

Third-party licenses are preserved in `THIRD_PARTY_NOTICES.txt`, regenerated from the locked runtime dependencies when the editor is built. No project-wide license for Jot's original source has been selected yet.

The app bundle uses an ad hoc signature for local use. See [Distribution](DISTRIBUTION.md) for installing a GitHub release, the current build's limitations, and the Developer ID signing and notarization required for a normal public download experience.
